MyNotes — Markdown Notes, Synced Everywhere

Started as a self-contained notes app in one HTML file, now a live site with a Node/Express backend and Postgres, so every device sees the same notebook. Organized like OneNote — notebooks › sections › pages › subpages, color-coded from the sidebar — with page history you can restore, Quick Notes, paragraph tags with a Find Tags summary, wikilinks, a split edit/preview pane, PowerShell syntax highlighting, image paste, and a focus timer. IndexedDB keeps an offline copy: edits save on-device when the server is unreachable and sync when the connection returns. Every dialog is built in-app, login is rate-limited, and the whole stack deploys from one Render blueprint.
